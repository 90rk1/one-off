# Libreplan

This project provides a local deployment environment for LibrePlan using Docker Compose.

```bash
mkdir patches
wget https://repo1.maven.org/maven2/org/codehaus/woodstox/stax2-api/4.2.1/stax2-api-4.2.1.jar -O ./patches/stax2-api-4.2.1.jar
```

```bash
docker compose up -d
```

http://localhost:8080
